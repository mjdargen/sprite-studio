Sprite Studio

Make sprite sheets and tile sheets for Pygame Zero Plus. Everything stays on your computer.

Sprite Studio can't run when index.html is opened straight from a folder, because browsers only load its code from a web server. Use the website, or run python serve.py in this folder and go to http://localhost:8000.
